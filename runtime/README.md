# Bundled LibreOffice runtime

LibreOffice 26.2.5.2, Windows x86-64, build cd7284b4cbbfeb507e630c1aac019f4157393acb. Includes LibreOffice Python 3.12.13 and UNO.

This project-local runtime was packaged from the matching LibreOffice installation on the maintainer's computer. It is not the separately branded PortableApps distribution. All installed program resources and license notices are retained; the redundant MSI installer is omitted. No personal LibreOffice profile is included in this archive.

Upstream: https://www.libreoffice.org/
Source releases: https://downloadarchive.documentfoundation.org/libreoffice/old/26.2.5.2/src/
Source repository: https://git.libreoffice.org/core

The archive retains LICENSE.html, license.txt, NOTICE, CREDITS.fodt, and component notices. Consult those files for LibreOffice and third-party license terms. Dashboard source licensing does not replace these notices.

The extracted runtime was tested for Python/UNO startup and Calc formula execution. A clean Windows machine without a system LibreOffice installation has not yet been tested.
